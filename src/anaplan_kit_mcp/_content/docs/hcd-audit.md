# Human-Centered Design Audit

Grade: 79 / B+

## HCD Read

This is a strong learning and reference kit for new Anaplan model builders. It is task-oriented, beginner-aware, and organized around real work: formulas, methodology, cookbook recipes, blueprints, tutorials, exercises, and API tooling.

## Evidence

- Clear target: new Anaplan model builder or consultant.
- Multiple entry points by job: learn, look up syntax, solve a task, understand methodology, practice, integrate.
- Reading conventions label Level, Area, PLANS, DISCO, and Planual context.
- Cookbook and blueprints reflect real work scenarios.
- CI checks links, markdown, blueprint conventions, and Python tooling.

## Main Gaps

- Learning is mostly document-based; interactive checkpoints are limited.
- No visible learner feedback or confusion loop.
- Real tenant constraints are explained, but practice validation could be more guided.

## Recommended Improvements

1. Add "what job are you trying to do?" navigation on the README or docs index.
2. Add short exercises at the end of each major learning section.
3. Add a learner self-assessment before Level 1, Level 2, and Level 3 paths.
4. Add a field-notes section for real implementation mistakes and fixes.
5. Add feedback capture: missing recipe, confusing formula, stale official-doc behavior.
