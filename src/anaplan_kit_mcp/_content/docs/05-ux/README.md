# User Experience — New UX & Classic Dashboards

> **Level:** L1 · **Area:** UX · **PLANS:** Logical, Sustainable

A model is only as good as the screens planners actually use. This section covers how you
**present** a model to its users: the modern **New UX** (Apps, Pages, Boards, Worksheets)
and the older **classic dashboards** you'll still meet in legacy models.

## New UX vs Classic — the short version

Anaplan has two ways to build user interfaces, and as a new builder you should know both:

| | **New UX** (current) | **Classic dashboards** (legacy) |
| --- | --- | --- |
| Container | **Apps** holding **Pages** | Modules' **Dashboards** tab |
| Page types | **Boards** and **Worksheets** | A single dashboard layout |
| Built from | **Cards** placed on a page | Published grids, charts, text |
| Status | What you build new today | Legacy — not for new build, but still widely live in existing tenants |
| Where you build | Anaplan **UX** (App designer) | Inside the **classic** model interface |

> **Build new interfaces in the New UX.** Reserve classic-dashboard knowledge for reading,
> maintaining, or migrating older models. *(Sustainable.)*

The underlying model is identical — UX is a *presentation layer* over the same modules and
line items. A card on a page and a grid on a classic dashboard can show the very same module
view; they just live in different interface generations.
